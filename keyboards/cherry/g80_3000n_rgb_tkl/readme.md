# Cherry G80-3000N RGB TKL

G80-3000N RGB TKL

Keyboard Maintainer: [as32](https://github.com/as32)<br />
Based on Womier k87 by: [Adam Honse](https://github.com/CalcProgrammer1)<br />
Hardware Supported: SN32F248BF<br />
<br />
Make example for this keyboard (after setting up your build environment):<br />

    make cherry/g80_3000n_tkl_rgb:default
